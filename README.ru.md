# Dabber

[English version](README.md)

Dabber — небольшое приложение для строки меню macOS, которое записывает звук, играющий на Mac, и то, что слышат ваши
микрофоны.

- Звук Mac и каждый выбранный микрофон записываются **отдельными дорожками**, плюс **стереомикс** всех источников.
- Если микрофон отключился во время записи (например, AirPods вынули из ушей или положили в футляр), запись не
  останавливается: Dabber ждёт устройство и продолжает, когда оно вернётся.
- **Запасной микрофон**: пока записываемый микрофон потерян, Dabber записывает запасной микрофон (по умолчанию
  встроенный микрофон Mac) в отдельную дорожку. Если у AirPods сядет батарея, ваш голос не пропадёт.
- Если включённый микрофон молчит 10 секунд, пока Mac воспроизводит звук, значок в строке меню показывает
  предупреждение. Потерянный микрофон видно во время записи, а не после неё.
- **Отметки**: нажмите Mark в важный момент и при желании введите комментарий. Отметки становятся главами в
  записанных файлах и сохраняются в `marks.txt`.
- **Слайды** (по желанию): с включённым «Record slides» Dabber раз в 2 секунды делает снимок экрана, а после Stop
  собирает видео: играет микс, а каждое изменение экрана остаётся на картинке до следующего изменения. Видео экрана
  не пишется.
- **Очистка микрофонов** (включена по умолчанию): после Stop из дорожек микрофонов убирается звук звонка, который
  микрофон услышал из динамиков Mac (эхо), и ровный фоновый шум.
- **Расшифровка** (на вашем Mac): текст и субтитры для каждой записи, с подписями «Я» и «Собеседники».
- **Названия из календаря**: запись называется по событию календаря, которое идёт сейчас (или начнётся в ближайшие
  15 минут). Название можно изменить во время записи.
- Папку для готовых записей выбираете вы.
- **Виртуальный микрофон «Dabber Mic»** (по желанию): приложения для звонков, OBS или программы записи экрана могут
  выбрать «Dabber Mic» как микрофон и получать звук Mac, смешанный с вашим настоящим микрофоном. Звук выбранных
  приложений (по умолчанию Safari) туда не попадает, чтобы собеседник не слышал сам себя.

Зачем он нужен: другие программы записи иногда теряли дорожку микрофона, например когда AirPods посреди записи
переключались в режим звонка, и это обнаруживалось только после звонка. Dabber записывает каждый источник
независимо и предупреждает прямо во время записи.

Dabber собирается из исходников на вашем Mac. Готовой сборки для скачивания нет.

## Требования

- **macOS 26 или новее** (`LSMinimumSystemVersion` 26.0).
- **Mac на Apple Silicon.** Драйвер виртуального микрофона собирается только под `arm64`. На Mac с Intel приложение
  не проверялось.
- **Command Line Tools для Xcode.** Установка в Терминале: `xcode-select --install`. Полный Xcode не нужен.
- **Место на диске:** около 1,5 ГБ на Command Line Tools и до 1 ГБ на папки сборки внутри репозитория. Во время записи
  Dabber хранит несжатый звук во временной папке: около 1,4 ГБ в час на звук Mac и около 0,7 ГБ в час на каждый
  микрофон, плюс до 500 МБ в час на слайды. Запись не начнётся, если свободно меньше 2 ГБ, а меню предупредит, когда
  места останется меньше чем примерно на 20 минут записи. Готовые файлы намного меньше (сжатый AAC). Речевая модель
  занимает около 470 МБ. Пока запись расшифровывается, временные файлы занимают около 0,5 ГБ на час стереозвука. Если
  Dabber упадёт во время расшифровки, он удалит эти файлы при одном из следующих запусков, когда им будет больше часа.

### Какие разрешения запросит приложение

| Разрешение | Когда запрашивается | Зачем |
| --- | --- | --- |
| Микрофон | Первая запись (или первое использование виртуального микрофона) с микрофоном | Чтобы записывать микрофоны |
| Запись системного звука | Первая запись (или первое использование виртуального микрофона) со звуком Mac | Чтобы записывать звук других приложений |
| Мониторинг ввода | Первая запись | Чтобы заметить двойное нажатие левого Option (горячая клавиша Mark). Dabber только слушает и только во время записи. Если отказать, ставьте отметки кнопкой Mark |
| Запись экрана | Первая запись с включённым Record slides | Чтобы делать снимки экрана для видео со слайдами |
| Календари (полный доступ) | Первая запись | Чтобы прочитать название текущего события и назвать по нему запись. Dabber только читает события. Если отказать, записи называются по дате и времени |

## Установка

Откройте Терминал и выполните команды по очереди.

1. Скачайте код и перейдите в его папку:

   ```sh
   git clone https://github.com/semyonf/Dabber.git dabber
   cd dabber
   ```

2. Создайте сертификат для подписи (один раз на Mac):

   ```sh
   scripts/make-cert.sh
   ```

   Скрипт создаёт в связке ключей «вход» (login) самоподписанный сертификат для подписи кода с именем «Dabber Dev» и
   помечает его как доверенный для подписи кода. macOS попросит пароль, чтобы изменить настройки доверия. Ничего
   никуда не отправляется.

   Зачем это нужно: macOS запоминает разрешения на микрофон и системный звук для конкретного подписанного
   приложения. С постоянным сертификатом выданные разрешения сохраняются после каждой пересборки и обновления. Без
   него macOS спрашивала бы снова после каждой сборки. Если сертификат уже есть, скрипт сообщит об этом и ничего не
   сделает.

3. Соберите и установите приложение:

   ```sh
   scripts/install-app.sh
   ```

   Скрипт собирает Dabber, подписывает его сертификатом «Dabber Dev» и копирует в `/Applications/Dabber.app`. Если
   Dabber запущен, скрипт сначала закрывает его и ждёт, пока Dabber доделает записи, но не больше 10 минут. Если
   Dabber за это время не закрылся, скрипт останавливается и не заменяет его. Другое приложение с тем же именем скрипт
   перезаписывать откажется.

4. Запустите Dabber из папки «Программы» или через Spotlight. У него нет значка в Dock и нет окна: найдите значок
   волны в строке меню и нажмите на него.

5. Нажмите **● Record** один раз, чтобы появились запросы разрешений, и разрешите их. Проверить их можно позже в
   Системных настройках > Конфиденциальность и безопасность.

### По желанию: виртуальный микрофон

```sh
scripts/install-driver.sh
```

Запускайте **без** `sudo`: скрипт собирает драйвер и подписывает его вашим сертификатом, а потом сам запрашивает
пароль, чтобы скопировать `DabberMic.driver` в `/Library/Audio/Plug-Ins/HAL/`. После этого он перезапускает звуковую
службу macOS, поэтому **весь звук пропадёт на несколько секунд**.

Проверка: откройте Системные настройки > Звук > Вход. В списке должен быть «Dabber Mic». В меню Dabber раздел
VIRTUAL MIC больше не пишет «Driver not installed». Если пишет, закройте Dabber (Quit в его меню) и запустите снова.

## Использование

### Запись

1. Нажмите на значок в строке меню. В разделе RECORDING перечислены **Mac audio** (звук Mac) и все микрофоны. При
   первом запуске включены звук Mac и системный микрофон по умолчанию. Источники включаются и выключаются флажками
   (во время записи нельзя). Включённое, но отсутствующее устройство показано с пометкой «(not connected)».
2. Нажмите **● Record**. Значок в строке меню сменится на символ записи, пойдёт таймер. У каждого источника есть
   индикатор уровня.
3. Нажмите **■ Stop**. Секунду-две на кнопке написано «Stopping…», потом снова «● Record»: следующую запись можно
   начать сразу. Dabber кодирует файлы в фоне и потом переносит запись в папку для готовых записей. Пока это идёт,
   под кнопкой написано «Finishing: <имя папки>…» или «Finishing N recordings…», если ждут несколько записей. Они
   доделываются по одной, в том порядке, в каком были остановлены. **Show last recording** открывает в Finder ту, что
   доделана последней.

Если закрыть Dabber во время записи или пока записи ещё доделываются, он сначала завершит их все
(«Finalizing before quit…»). Это касается и записей, которые Dabber доделывает при запуске после неожиданного
закрытия. Для них он может сначала до минуты ждать, пока загрузится речевая модель. Расшифровка входит в эту работу.
Если модель уже загружена, расшифровка занимает около 15 секунд на час звука в каждой дорожке.

Каждая запись — папка с именем `ГГГГ-ММ-ДД ЧЧ-ММ <название>` (только дата и время, если названия нет). Если папка с
таким именем уже есть, к имени добавляется номер. Внутри:

```
2026-09-24 14-00 Weekly sync/
  2026-09-24 14-00 Weekly sync.m4a   микс всех источников (стерео)
  computer audio.m4a                 звук Mac (стерео)
  mic - AirPods.m4a                  по файлу на каждый микрофон (моно)
  mic - MacBook Air Microphone (backup).m4a
                                     только если понадобился запасной микрофон (моно)
  2026-09-24 14-00 Weekly sync.mp4   только с Record slides: микс с экраном в виде слайдов
  marks.txt                          только если были отметки
  transcript.txt                     текст с временем, говорящими и отметками, если расшифровка удалась
  transcript.srt                     тот же текст в виде субтитров для любого плеера
  session.json                       технические данные: источники, пропуски, перезапуски
```

Если при нажатии Record не подключён ни один из включённых микрофонов, Dabber записывает вместо них системный
микрофон по умолчанию и сообщает об этом, например «AirPods not connected — recording MacBook Air Microphone». Если
часть включённых микрофонов подключена, а часть нет, записываются подключённые, а отсутствующие называются в
предупреждении.

### Запасной микрофон

**Backup mic:** под списком источников выбирает микрофон, который подменяет потерянный записываемый микрофон, или
None. При первом запуске это встроенный микрофон Mac (None, если его нет). Записываемые микрофоны помечены в этом
списке «(recorded)»: записываемый микрофон запасным не служит.

Если записываемый микрофон пропадает во время записи (например, у AirPods села батарея) или отказывает, Dabber
начинает записывать запасной микрофон в отдельную дорожку `mic - <имя> (backup).m4a`. Меню сообщает об этом,
например «AirPods: waiting for device — recording MacBook Air Microphone (backup)». Когда все записываемые микрофоны
снова работают несколько секунд подряд, запасной встаёт на паузу. Если микрофон пропадёт снова, запасной продолжит ту
же дорожку. На месте пауз в этой дорожке тишина. Дорожка запасного микрофона тоже входит в микс с той же громкостью,
что и микрофон, который она заменяет, поэтому микс не становится тише. Потеря звука Mac запасной микрофон не
включает.

Микрофон, которого не было при нажатии Record, включает запасной, только если он подключится, начнёт запись и снова
пропадёт. Если запасной микрофон за всю запись ничего не записал, дорожки запасного микрофона нет. Если запасной
микрофон сам входит в число записываемых, в этой записи он запасным не служит. Если запасной не удаётся включить,
меню пишет «Backup mic <имя> failed (…)», и Dabber пробует снова каждые несколько секунд. Если он нужен, но не
подключён, меню пишет «Backup mic <имя> not connected», и Dabber включит его, как только он появится.

Запасной микрофон можно сменить во время записи. Если запасной в этот момент не пишет, новый выбор сработает при
следующей потере. Если запасной пишет, старый встаёт на паузу, а новый микрофон сразу начинает писать в свою дорожку,
например `mic - USB (backup).m4a`. Если вернуть микрофон, у которого в этой записи уже есть дорожка запасного, он
продолжит ту же дорожку. Выбор None или записываемого микрофона выключает запасной до конца записи или до выбора
другого микрофона. Каждая дорожка запасного микрофона, в которую что-то записалось, остаётся в записи и в миксе.

### Отметки

Во время записи нажмите **Mark**. Появится поле комментария: введите короткую заметку и нажмите Return или оставьте
пустым. Отметки без комментария называются «Mark 1», «Mark 2» и так далее. В списке под кнопкой видно время каждой
отметки; кнопка с минусом удаляет отметку.

**Горячая клавиша:** дважды быстро нажмите левый Option (⌥⌥), чтобы поставить отметку, не открывая меню.
Короткий звук подтверждает отметку; комментарий можно дописать потом в меню. Работает только во время записи и
только при быстром двойном нажатии одного левого Option (Option с буквой отметку не ставит). Нужно разрешение
«Мониторинг ввода»; без него меню пишет «Allow Input Monitoring for the ⌥⌥ hotkey» (Системные настройки >
Конфиденциальность и безопасность > Мониторинг ввода, затем закройте и снова запустите Dabber).

После Stop отметки становятся главами (плюс первая глава «Start» на 0:00) в миксе и в файлах дорожек. Главы
проверены в QuickTime Player, Просмотре (Preview) и VLC (IINA и приложения на iPhone не проверялись). Те же отметки
записываются в `marks.txt` строками вида `ЧЧ:ММ:СС  комментарий`.

### Слайды

Включите **Record slides** под списком источников до нажатия Record (во время записи переключить нельзя). Во время
записи Dabber раз в 2 секунды снимает экран, на котором находится указатель мыши. Снимок сохраняется, только если
экран изменился; мигающий текстовый курсор и часы в строке меню не считаются. Сам указатель на снимок не попадает.

После Stop Dabber собирает `<название>.mp4` рядом с миксом: тот же звук, видео HEVC в родном разрешении экрана (не шире 3456 пикселей),
те же главы. Каждый сохранённый снимок показывается до следующего; первый показывается с 0:00. После сборки
снимки удаляются. Если видео собрать не удалось, меню пишет «Slides video failed: …», звуковые файлы готовы как
обычно, а снимки остаются в папке `frames` внутри записи (файлы HEIC, названные по наносекундам от начала).

В видео попадает всё, что было на этом экране: уведомления, чаты, пароли на экране. Для записей, где это важно,
выключайте Record slides.

### Очистка микрофонов

Без наушников микрофон слышит и звонок из динамиков Mac, поэтому собеседники записываются дважды: чисто в дорожке
звука Mac и с опозданием и эхом комнаты в дорожке микрофона. С включённым **Clean up microphones** (под списком
источников, по умолчанию включено) Dabber после Stop убирает это из каждой дорожки микрофона, до кодирования, микса и
расшифровки:

- **Эхо звука Mac.** Dabber измеряет, насколько позже микрофон слышит звук Mac, затем адаптивный фильтр (так же
  работают эхоподавители в приложениях для звонков) учится тому, как звук доходит до микрофона, и вычитает его. То,
  что остаётся после фильтра, дополнительно приглушается. Когда вы говорите одновременно с собеседником, ваш голос
  остаётся, хотя в эти моменты может звучать чуть тоньше. Микрофон, который не слышит звук Mac (наушники), получает
  только шумоподавление.
- **Ровный шум**: вентиляторы, гул, кондиционер, шум машин за окном и всё ниже примерно 70 Гц. Короткие резкие звуки
  (стук, щелчок клавиатуры, дверь) не ровный шум и в основном остаются.

Фильтру нужно несколько секунд речи собеседника, чтобы изучить комнату, поэтому в самых первых словах звонка может
остаться немного эха. В `session.json` записаны очищенные дорожки (`cleanedMics`) и измеренная задержка
(`echoDelayMillis`). Переключатель читается, когда запись доделывается, поэтому действует на записи, остановленные
после изменения. Выключите его, чтобы дорожки микрофонов остались ровно такими, как записаны: в готовых файлах очистку
не отменить.

### Расшифровка и субтитры

После Stop Dabber расшифровывает запись на вашем Mac с помощью речевой модели Parakeet. Ничего не уходит за пределы
Mac. Каждый источник расшифровывается отдельно: реплики микрофонов (запасного тоже) подписаны «Я», реплики звука Mac
подписаны «Собеседники». Стереозвук Mac перед этим сводится в моно. Строки, в которых модель не уверена (средняя
уверенность по словам ниже 0,6), в расшифровку не попадают. Так отсекаются фразы, которые модель придумывает по
почти полной тишине на тихом микрофоне.

Если вы слушаете через динамики, а не через наушники, микрофон слышит и звук Mac. Dabber убирает из реплик «Я» слова,
которые повторяют звук Mac. Отдельное слово всё же может остаться. Может остаться и речь, которую модель расслышала
через микрофон иначе.

- `transcript.txt`: текст с временем, говорящими и вашими отметками.
- `transcript.srt`: субтитры для любого плеера. Оба файла лежат рядом с записью.
- В видео со слайдами есть русская дорожка субтитров. При открытии видео она выключена. В QuickTime Player её
  включают через View > Subtitles. Если дорожку субтитров записать не удалось, видео сохраняется без неё, а меню
  пишет «Subtitles left out of the video: …».

Если Transcribe включён, модель (около 470 МБ) скачивается и подготавливается в фоне при запуске Dabber. В первый раз
это занимает около 2-5 минут и требует интернета. Модель хранится в
`~/Library/Application Support/FluidAudio/Models/parakeet-tdt-0.6b-v3-coreml`. Пока модель загружается, под
переключателем Transcribe видна строка состояния. Во время скачивания она показывает «Downloading speech model… 37%».
Затем Dabber подготавливает модель, и строка показывает «Preparing speech model…». В первый раз подготовка может занять
несколько минут. Когда модель готова, строка пишет «Speech model ready». Если загрузка не удалась, строка пишет
«Speech model failed: …» и причину. После последней разрешённой попытки она добавляет «Dabber will try again at the next launch.». Если запись
закончилась раньше, чем модель готова, она выдаётся без расшифровки, а меню пишет «Transcript failed: the speech
model is not ready yet».
Если загрузить модель не удалось, следующая запись тоже выдаётся без расшифровки, а Dabber в это время снова загружает
модель в фоне. После трёх неудачных загрузок Dabber перестаёт пытаться, пока его не перезапустят. Ошибки сети в эти
три попытки не входят: нет соединения, загрузка зависла или превысила лимит запросов, сервер ответил ошибкой. Для них
есть свой предел: после десяти таких ошибок Dabber тоже перестаёт пытаться до перезапуска. Если же файла модели нет на
сервере или в кэше, это одна из трёх попыток. Записи короче одной секунды не расшифровываются. Если
расшифровка записи дважды не дошла до конца (из-за сбоя, принудительного закрытия или отключения питания), в третий
раз Dabber её не запускает. Запись выдаётся без расшифровки, а меню пишет «Transcript failed: not attempted:
transcription did not finish twice».

Переключатель **Transcribe** под списком источников включает и выключает расшифровку. По умолчанию он включён. Когда
он выключен, записи выдаются без расшифровки, а меню не сообщает об ошибке. В этом случае Dabber не загружает модель
при запуске. Если переключатель включить, Dabber начнёт загружать модель. В отличие от Record slides, его можно
переключить во время записи. Dabber проверяет переключатель, когда начинает доделывать запись после Stop. Если
выключить его, пока идёт расшифровка, она всё равно дойдёт до конца.

Если Dabber упал во время расшифровки, запись не теряется. После двух незаконченных попыток Dabber выдаёт её без
расшифровки, как описано выше. Если Dabber падает при расшифровке каждой записи, выключите Transcribe. Если Dabber
остановился, пока загружалась модель (из-за сбоя, принудительного закрытия или отключения питания), при следующем
запуске он сам выключит Transcribe. Меню напишет «Transcribe turned off: the speech model stopped Dabber while
loading. Turn it on to try again.». Записи, оставшиеся с прошлого запуска, Dabber тогда доделает без расшифровки.
Обычный выход через Quit во время загрузки модели переключатель не выключает.

Для проверок есть команда без окна: `Dabber --transcribe <аудиофайл>` печатает строки одного файла с временем.

### Названия записей

При нажатии Record Dabber ищет в календарях событие, которое идёт сейчас или начнётся в ближайшие 15 минут (события
на весь день не учитываются), и берёт его название. Поле **Name** показывает название во время записи; его можно
заменить или очистить. Название применяется, когда запись завершена. Полное имя записи также записывается в тег
названия файла микса. Символы `/` и `:` в названии заменяются на `-`.

### Папка для записей

Строка **Folder** показывает, куда попадают готовые записи (по умолчанию `~/Recordings/Dabber`). **Change…**
выбирает другую папку, например в iCloud Drive или на внешнем диске.

Dabber всегда сначала пишет в `~/Library/Application Support/Dabber/Sessions` и переносит запись в выбранную папку
только после её завершения. На другой диск он копирует, проверяет копию и затем удаляет локальную. Если папка
недоступна (например, диск извлечён), запись остаётся в локальной папке, меню показывает «Saved in the local folder:
…», а Dabber пробует снова после следующей записи и при следующем запуске.

### Виртуальный микрофон

Нужен драйвер (см. «Установка»).

1. В разделе VIRTUAL MIC включите переключатель.
2. **Mac audio**: передавать звук, который играет Mac. Под «except:» перечислены приложения, звук которых не
   передаётся. По умолчанию это Safari: если вы разговариваете в Safari, звук самого звонка (голоса собеседников)
   иначе вернулся бы к ним через Dabber Mic, и они слышали бы сами себя (эхо). Если звоните через другое приложение,
   добавьте его кнопкой **+ app**; убрать приложение можно кнопкой с минусом. На записи этот список не влияет.
3. **Microphone**: выберите микрофон для подмешивания или None.
4. В Zoom, Google Meet, OBS, программе записи экрана или любом другом приложении выберите микрофон **Dabber Mic**.

Строка статуса показывает «Waiting for an app to use Dabber Mic», пока ни одно приложение его не открыло, затем
«Sending» с индикатором уровня. Настоящий микрофон Dabber открывает только пока какое-то приложение использует
Dabber Mic. Виртуальный микрофон работает независимо от того, идёт ли запись.

## Обновление

```sh
cd dabber
git pull
scripts/install-app.sh
```

Разрешения сохраняются, пока сохранён сертификат «Dabber Dev». Если `git pull` изменил что-то в `Driver/`, снова
выполните `scripts/install-driver.sh`.

## Удаление

1. Закройте Dabber и удалите `/Applications/Dabber.app`.
2. Драйвер виртуального микрофона: `scripts/uninstall-driver.sh` (спросит пароль; звук пропадёт на несколько
   секунд).
3. Сертификат: `security delete-identity -c "Dabber Dev" -t` или удалите «Dabber Dev» в приложении «Связка ключей»
   (связка «вход», «Мои сертификаты»).
4. Временная папка записей и настройки: удалите `~/Library/Application Support/Dabber` (сначала убедитесь, что там
   нет нужных незавершённых записей), затем выполните `defaults delete local.dabber.Dabber`.
5. По желанию сбросьте разрешения: `tccutil reset All local.dabber.Dabber`.

Записи в папке для готовых записей не затрагиваются.

## Решение проблем

- **Дорожка звука Mac пустая.** Откройте Системные настройки > Конфиденциальность и безопасность > Запись экрана и
  системного звука и разрешите Dabber. Без этого разрешения Dabber не может записать звук Mac.
- **Предупреждение «Screen: no permission».** Record slides включён, но Dabber не разрешено снимать экран. Откройте
  Системные настройки > Конфиденциальность и безопасность > Запись экрана и системного звука, разрешите Dabber в
  верхнем списке (не в «Только запись системного звука»), затем закройте и снова запустите Dabber. Звук
  записывается в любом случае.
- **Предупреждение «… not connected — recording …» или «…: no signal for 10 s».** Первое значит, что включённого
  микрофона не было при старте и записывается другой. Второе — микрофон молчит 10 секунд, пока Mac играет звук:
  проверьте, что включён нужный микрофон, он не выключен, и Dabber разрешён в Конфиденциальность и безопасность >
  Микрофон.
- **Предупреждение «… waiting for device — recording … (backup)» или «Backup mic … not connected».** Записываемый
  микрофон пропал. Первое значит, что вместо него пишется запасной микрофон. Второе значит, что запасного микрофона
  тоже нет. Тогда то, что слышал только потерянный микрофон, не записывается, пока один из них не вернётся. Остальные
  записываемые микрофоны продолжают запись. Выберите в **Backup mic:** микрофон, который всегда на
  месте (обычно встроенный).
- **Музыка или звонок в AirPods звучат хуже во время записи.** Когда какое-либо приложение использует микрофон
  AirPods, они переходят в режим звонка Bluetooth с более низким качеством воспроизведения. Так работают
  Bluetooth-гарнитуры, это не настройка Dabber. Если важно качество звука, используйте другой микрофон, например
  встроенный микрофон Mac.
- **«Dabber Mic» нет в списке микрофонов.** Драйвер не установлен: выполните `scripts/install-driver.sh`. Меню Dabber
  в этом случае пишет «Driver not installed».
- **После обновления Dabber снова спрашивает разрешения.** Приложение подписано другим сертификатом, обычно потому,
  что «Dabber Dev» удалили и создали заново. Разрешите ещё раз; дальше они сохранятся для сборок с этим
  сертификатом.
- **Предупреждение «Could not read: …».** Кусок дорожки повреждён, обычно из-за отключения питания или сбоя. Dabber
  собрал запись без этого куска (на его месте тишина) и оставил повреждённый файл `.caf` в папке записи.
- **«Finishing…» идёт долго.** После Stop Dabber кодирует каждую дорожку и микс в фоне, с низким приоритетом, чтобы не
  мешать новой записи. Чем длиннее запись и больше источников, тем дольше; ещё дольше, если папка для записей на другом
  диске или процессор занят другими приложениями. Расшифровка добавляет около 15 секунд на час звука в каждой дорожке,
  если модель уже загружена, а Clean up microphones ещё раз читает запись и обрабатывает каждую дорожку микрофона. Записывать в это время можно; если закрыть приложение, Dabber дождётся сам. Если Dabber
  закрылся аварийно, незавершённые записи будут доделаны при следующем запуске.

## Для разработчиков

- `Sources/DabberCore`: движок, финализация, модели (покрыты тестами). `Sources/Dabber`: приложение для строки меню и
  режим без интерфейса для проверок на железе. `Sources/DabberSpeech`: распознавание речи моделью Parakeet через
  FluidAudio. Это отдельная цель сборки (target), поэтому `DabberCore` не зависит от FluidAudio. `Driver/`: виртуальный
  микрофон, форк BlackHole (см. `Driver/NOTICE`). `scripts/`: скрипты сборки, установки и тестов.
- Тесты запускаются через `scripts/test.sh`. Если установлены только Command Line Tools, обычный `swift test` не
  находит плагин макросов Swift Testing; скрипт передаёт путь к нему.
- `scripts/build-app.sh` собирает `build/Dabber.app` без установки.
- `scripts/make-echo-tests.py` собирает в `build/echo-tests` тестовые записи для очистки микрофонов: звонок без
  наушников в трёх смоделированных комнатах, с дорожкой звука Mac, дорожкой микрофона и тем, что от неё должен оставить
  идеальный чистильщик. Нужен Python с `numpy scipy soundfile pyarrow`; при первом запуске скачивает 9 МБ речи
  LibriSpeech.
- В `docs/` лежат спецификации, планы реализации и результаты экспериментов с железом («spikes»), сделанных при
  разработке Dabber.
