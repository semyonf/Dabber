# iPad broadcast spike

Finds out what an iPad lets a ReplayKit broadcast extension record during calls. Build steps, the test plan and the
results table are in [docs/spikes/2026-11-04-spike-ipad-broadcast.md](../../docs/spikes/2026-11-04-spike-ipad-broadcast.md).

Quick start on the Mac: `brew install xcodegen`, then `./make-project.sh TEAM_ID`, then run on the iPad from Xcode.
